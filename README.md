# court mate — 테니스 회원·스케줄 관리 앱

외부 서버 없이 **브라우저 로컬 저장소(IndexedDB)** 로 동작하는 개인용 테니스 회원·레슨 스케줄 관리 앱입니다. React + Vite 기반이며, 데이터 확인·백업은 **CSV 내보내기/가져오기**로 합니다.

## 주요 기능
- 로그인(관리자 전용): 생년월일 6자리 + 전화 뒤 4자리
- 스케줄표: 달력/리스트 보기 전환, 회원별 조회 필터, 일정 추가·수정·삭제
- 레슨 시작/종료 제어(시작 → 진행중, 종료 → 완료 및 이용권 차감)
- 스케줄 시간 중복 방지 경고
- 이용권 관리: 회원별 이용권 추가/삭제, [사용/총] 회차 표기, 완료 자동 전환
- 완료 회원 재등록 알림(문자 앱 연동)
- 상단 통계 카드: 총 회원 수 / 이번달 레슨 횟수(남은/전체) / 이번달 레슨 회원수
- 정보 관리(CSV): 스케줄·회원·이용권 각각 내보내기/가져오기/템플릿
- 연단위 아카이브: 지난해 종료 일정 CSV 아카이빙 + 과거 데이터 읽기 전용 조회
- 앱 내 사용설명서(브라우저 인쇄로 PDF 저장)

## 데이터 저장
- 데이터는 사용 중인 브라우저의 IndexedDB에 저장됩니다. (`court-mate-db`)
- 브라우저/기기 간 이동, 백업은 **정보 관리 → 내보내기/가져오기(CSV)** 로 합니다.
- 최초 실행 시 익명 처리된 샘플 데이터가 들어 있습니다. (관리자 계정 제외)

## 실행 방법,
```bash
npm install
npm run dev     # 개발 서버 (크롬 권장)
npm run build   # 프로덕션 빌드
npm run lint    # 정적 검사
```

## 배포 계획
- 1단계: PC 크롬에서 기능 검증·안정화 (완료)
- 2단계: 안드로이드 APK 패키징 — Capacitor 설정 완료. 빌드 절차는 `APK_BUILD.md` 참고.

## APK 빌드 (요약)
```bash
npm run build
npx cap sync android
npx cap open android   # Android Studio에서 Build → Build APK
```
자세한 절차·요구 사항은 `APK_BUILD.md`를 보세요. (JDK 17/21 + Android SDK 필요)
