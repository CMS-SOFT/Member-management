# 안드로이드 앱(APK) 만들기 가이드 (court mate)

소스를 고친 뒤 이 문서를 따라 하면 안드로이드 앱(APK)을 만들 수 있습니다.
이 프로젝트는 **Capacitor** 로 웹앱을 안드로이드로 감쌉니다. (android 폴더가 이미 구성돼 있음)

---

## 0. 준비 (최초 1회만)

APK 빌드는 다음이 설치돼 있어야 합니다:

1. **JDK 17** (안드로이드 빌드 호환 버전)
   - ⚠️ 이 PC에는 JDK 25가 깔려 있어 안드로이드 빌드가 안 됩니다. JDK 17로 맞춰야 함.
   - 확인: `java -version` → 17 이어야 함
   - 설치: Temurin(Adoptium) JDK 17 권장 → https://adoptium.net
2. **Android SDK** (Android Studio 설치 시 함께 설치됨)
   - Android Studio: https://developer.android.com/studio
   - 설치 후 SDK 경로를 환경변수 `ANDROID_HOME` 에 지정
3. Node.js + 프로젝트 의존성:
   ```
   npm install
   ```
   - Capacitor 도구는 이미 설치돼 있음 (@capacitor/core, cli, android 등)

> SDK/JDK 설정이 어려우면 Android Studio 를 설치하는 것이 가장 쉽습니다.
> (SDK, 빌드도구, 에뮬레이터가 한 번에 설치됨)

---

## 1. 소스 수정 후 빌드 순서

프로젝트 폴더에서:

```
npm run cap:sync
```
- 이 한 줄이 `npm run build`(웹 빌드) + `npx cap sync android`(안드로이드 프로젝트에 반영)를 실행합니다.
- package.json 에 정의돼 있음.

그 다음 APK 생성:

### 방법 A. 명령줄로 디버그 APK (가장 빠름)
```
npm run apk:debug
```
- 내부적으로: build → cap sync → `android\gradlew.bat assembleDebug`
- 결과 APK 위치:
  ```
  android\app\build\outputs\apk\debug\app-debug.apk
  ```
- 이 APK 를 폰에 복사해 설치 (설정에서 "출처를 알 수 없는 앱 설치" 허용 필요)

### 방법 B. Android Studio 로 열어서 빌드 (권장, 오류 확인 쉬움)
```
npm run cap:open
```
- Android Studio 가 열리면 상단 메뉴 Build → Build APK(s)
- 또는 실제 폰 연결 후 Run 버튼으로 바로 설치/실행

---

## 2. 배포용 서명 APK (플레이스토어/정식 배포 시)

디버그 APK 는 테스트용입니다. 정식 배포하려면 서명이 필요합니다.

1. 서명 키 생성 (최초 1회):
   ```
   keytool -genkey -v -keystore courtmate.keystore -alias courtmate -keyalg RSA -keysize 2048 -validity 10000
   ```
2. `android\app\build.gradle` 의 signingConfigs 에 keystore 정보 추가
3. 릴리스 빌드:
   ```
   cd android
   gradlew.bat assembleRelease
   ```
   결과: `android\app\build\outputs\apk\release\app-release.apk`

> 서명 설정은 한 번만 해두면 됩니다. 자세한 값은 build.gradle 참고.

## 3. 주요 설정 파일

| 파일 | 역할 |
| --- | --- |
| `capacitor.config.json` | 앱 ID, 앱 이름, webDir(dist) 설정 |
| `android/` | 안드로이드 네이티브 프로젝트 (Capacitor가 생성) |
| `android/app/build.gradle` | 앱 버전, 서명, 최소 SDK 등 |
| `android/app/src/main/AndroidManifest.xml` | 권한(파일 저장 등) 설정 |

- 앱 이름/아이디를 바꾸려면 `capacitor.config.json` 수정 후 `npm run cap:sync`

---

## 4. 자주 나는 문제

| 증상 | 원인 / 해결 |
| --- | --- |
| gradlew 빌드 실패 (Unsupported class file / JDK 오류) | JDK 버전 문제. JDK 17 로 맞추기 (`java -version`) |
| `SDK location not found` | `ANDROID_HOME` 환경변수 미설정. Android Studio 설치/SDK 경로 지정 |
| 화면이 흰색/스타일 깨짐 | 웹 빌드 반영 안 됨. `npm run cap:sync` 다시 실행 |
| CSV 내보내기 안 됨 | 안드로이드는 파일 저장에 권한 필요. Manifest 권한 + @capacitor/filesystem 확인 |
| 앱 아이콘 기본값 | android 리소스의 아이콘 교체 필요 (res/mipmap) |

---

## 5. 한 줄 요약

```
npm run cap:sync
npm run apk:debug
```
→ `android\app\build\outputs\apk\debug\app-debug.apk` 를 폰에 설치

> 단, JDK 17 + Android SDK 가 이 PC에 설치돼 있어야 실제로 빌드됩니다.
> (현재 PC는 JDK 25 + SDK 미설치 상태라, 위 환경부터 갖춰야 함)
