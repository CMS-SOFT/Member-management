[통합 가이드] 테니스 레슨 회원 관리 시스템 (Court Mate)
이 문서는 Court Mate 시스템의 전체적인 기술 구조(개발자/관리자용)와 사용법(코치/초보 사용자용)을 모두 담은 통합 안내서입니다.

🛠️ Part 1. 시스템 기술 명세서 (Tech Spec)
1. 프로젝트 개요
목적: 테니스 레슨(개인 및 단체) 회원, 이용권, 일정 및 출석/횟수를 효율적으로 관리하기 위한 전용 시스템 구축.

타겟 사용자: 컴맹 사용자(코치 또는 관리자)가 복잡한 프로그램 설치나 데이터 관리 없이 직관적으로 사용할 수 있는 환경 제공.

핵심 가치:

엑셀 파일이나 구글 시트가 가진 데이터 유실, 동시성 오류, 복잡한 수식 관리의 한계를 극복.

사용자는 익숙한 표(Grid) 및 달력 형태의 UI로 간편하게 조작하되, 시스템 백그라운드는 강력한 관계형 데이터베이스로 안정성 확보.

2. 구체적인 기술 스택 및 실행 환경
① 프론트엔드 (사용자 UI 레이어): React (Vite 기반). 엑셀 시트와 유사한 직관적인 표 및 달력 형태의 대시보드 제공.

② 백엔드 (로컬 서버 레이어): Node.js (Express) 또는 Python (FastAPI). 프론트엔드와 DB 사이를 중계하며 레슨 완료 시 이용권 자동 차감 및 단체 레슨 인원 매핑 처리.

③ 데이터베이스 (스토리지 레이어): SQLite (Embedded DB). 서버를 따로 설치할 필요가 없는 파일 기반(tennis.db) 초경량 관계형 DB로 백업과 이동이 극도로 편리함.

④ 배포 및 확장성 전략: 사용자는 웹 브라우저나 실행 파일 하나로 즉시 사용 가능하며, 추후 멀티 기기 실시간 동기화 필요 시 백엔드와 SQLite 파일을 클라우드 호스팅으로 이전하여 확장 가능.

📖 Part 2. Court Mate 사용자 설명서
테니스 회원과 레슨 일정을 관리하는 앱입니다. 처음 쓰는 분도 쉽게 따라 할 수 있도록 정리했습니다.

1. 로그인하기
첫 화면에서 비밀번호를 입력하고 로그인합니다.

비밀번호 규칙: 생년월일 6자리 + 전화번호 맨 뒤 4자리 (예: 생일 01년 04월 20일, 전화번호 010-2222-1234 → 0104201234)

관리자 계정으로 지정된 분만 로그인할 수 있습니다.

2. 전체 화면 둘러보기
로그인하면 2개의 기본 메뉴와 상단 위젯을 볼 수 있습니다.

스케줄표: 달력에서 레슨 일정을 보고 추가·수정·삭제합니다.

회원정보: 회원 목록을 보고, 회원과 이용권을 관리합니다.

오늘 레슨 위젯: 화면 상단에 오늘 레슨 건수와 진행 예정 건수가 표시됩니다.

3. 레슨 일정(스케줄) 관리하기
달력에서 [＋ 일정 추가] 버튼을 누르면 새 일정을 만듭니다.

일정을 누르면 오른쪽에 수정 창이 열립니다.

시간은 30분 단위로 선택하며, 같은 날짜·시간에 다른 회원의 일정이 이미 있으면 경고창이 뜨며 저장이 막힙니다.

회원 스케줄 추가: 달력의 빈 날짜를 누르면 창이 열리며, 회원과 시간을 선택해 추가할 수 있습니다.

상단 통계 카드: 총 회원 수, 이번달 레슨 횟수(진행예정/전체), 이번달 레슨 회원수 표시.

레슨 시작 / 종료:

[시작]을 누르면 '진행중'으로 변경.

[종료]를 누르면 '완료' 처리되며 이용권이 1회 자동 차감.

회차 표기: 일정 옆 [3/8] 표시는 [사용한 횟수 / 전체 횟수]를 뜻합니다. 이용권을 모두 쓰면 자동 완료 처리와 알림이 뜹니다.

4. 회원 및 이용권 관리하기
자동 재등록: 이용권이 끝난 회원 목록 열에 [재등록] 버튼이 생성됩니다. 횟수와 요일/시간을 고르면 오늘 이후 날짜로 일정이 자동 생성됩니다.

일정 추가 제한: 이용권이 없거나 만료된 회원은 새 일정을 추가할 수 없습니다.

이용권 관리: 회원을 눌러 상세 창 아래의 이용권 영역에서 총 횟수를 넣고 [＋ 이용권 추가]를 누르거나 [✕]로 지울 수 있습니다.

5. 데이터 저장 및 엑셀 백업하기 (중요)
데이터를 엑셀로 관리하려면 화면 상단 [정보 관리 ▾] 버튼을 이용합니다.

내보내기: 현재 데이터를 엑셀 파일(CSV)로 다운로드 폴더에 저장.

가져오기: 엑셀에서 수정한 CSV 파일을 다시 불러와 전체 내용을 교체.

템플릿: 처음 대량 등록할 때 사용하는 빈 엑셀 양식.

6. 처음 실행 시 연습용 데이터 (샘플)
처음 실행 시 연습용 가상 데이터가 들어 있습니다. [정보 관리 ▾] → [데이터 초기화]를 누르면 관리자 계정만 남고 모든 가상 데이터가 지워집니다.

7. 지난 데이터 정리 및 조회 (아카이브)
연말정리: 작년에 완료된 일정을 CSV 파일로 다운받고 현재 화면에서 지워 화면을 가볍게 유지할 수 있습니다.

8. 자주 묻는 질문 & 9. PDF 저장
데이터는 컴퓨터/브라우저에 저장되므로, 다른 컴퓨터에서 쓰려면 [내보내기] 후 새 컴퓨터에서 [가져오기]를 진행해 주세요.

화면 상단 [사용설명서] 버튼을 눌러 인쇄 창에서 대상을 "PDF로 저장"으로 선택하면 파일로 보관할 수 있습니다.
